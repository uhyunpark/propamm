# propamm-bot

- `feeds.rs`: data-driven feed table (`FeedSpec`). Add a feed by adding a row, plus a test if it has a new frame shape.
- `connector.rs`: one task per feed, forwards `RawMessage` over a bounded mpsc. Reconnect, backoff, silence watchdog live here.
- `recorder.rs`: single consumer, hourly zstd JSONL under `data/raw`. Time comes from the message (`recv_unix_ns`) and `tick(now)`, so tests inject it.
- Run: `cargo run -p propamm-bot --release -- record` (`--duration N --out DIR` for smoke tests). No live-network tests in `make check`.
- `parse.rs`: enum-dispatched, stateful `Parser` per feed file (`Parser::for_feed(name)`): raw message -> `Event::{Bbo, Trade, Mark}`. Lenient: acks yield nothing, malformed frames return `ParseError`. A new feed needs a `Kind` variant, a fixture in `tests/fixtures/`, and a test (`every_recorded_feed_has_a_parser` guards the table).
- `replay.rs`: lazy zstd readers per feed plus a k-way merge by `recv_ns`. A truncated last frame (recorder still running) is warned about and skipped.
- `fair.rs`: `FairEngine` (`update(&Event)`, `fair(now_ns)`), params in `FairParams`/`Weights`. Coinbase events are ignored on purpose (held-out reference).
- `eval.rs`: one replay pass collects candidate fair values and the Coinbase series, metrics are pure functions over them. CLI: `propamm-bot eval --data DIR [--from/--to unix_s] [--latency-ms 150]`; Markdown to stdout, redirect to `docs/eval/`.
- Crate denies `unwrap_used`/`expect_used`; thiserror in lib, anyhow at the edge.
- Rustls needs the ring provider installed explicitly (done in `record`).
- `publish.rs`: pure publish policy (threshold, heartbeat, one per slot, skew, band clamp, halt) plus unit conversions. `pyth.rs`: breaker logic and Hermes poller (unreachable or stale means warn and continue). `run.rs`: the `run` loop (feeds, ws slot and Market subscription, RPC refresh, send, status polling). `chain.rs`: small JSON-RPC client over reqwest, tx building, SPL/ATA/compute-budget encoders (no `solana-client`). `subscribe.rs`: ws. `live.rs`: feeds into `FairEngine`. `config.rs`: `data/localnet.json`. `tools.rs`: `setup-local`, `force-price`, `pause`, `unpause`, `swap`.
- `serve.rs` (`run --serve 127.0.0.1:PORT [--faucet]`, contract: `docs/demo-contract.md`): axum `GET /config`, `WS /stream`, `POST /control`, `POST /faucet`. The bot loop only pushes into a bounded broadcast channel (skipped with no client; lagging clients are dropped), so publishing never waits on the server. `ControlState` (publishing, temporary offset with an injectable clock) is shared via `SharedControl`; the offset is applied to fair before skew and band clamp. Swap events come from `logsSubscribe` (mentions the program) decoded with `propamm-client`. Faucet: only with `--faucet` and an http(s) RPC whose parsed host is exactly `127.0.0.1` or `localhost` (`is_local_rpc`), mints with the admin key. `/stream` also checks the WS `Origin` against `ALLOWED_ORIGINS`. One outermost layer (`router(state, port)`) returns 403 unless `Host` is exactly `127.0.0.1:<bound port>` or `localhost:<bound port>` (DNS rebinding). `live.rs` also tracks venue BBOs (`with_venues`, display only). Demo default port: 8788 (8787 is often taken on dev machines); any 127.0.0.1 port works.
- `setup` (alias `setup-local`): `--cluster local|devnet`. Devnet needs `--admin-keypair`, never airdrops, checks the admin balance and prints the SOL needed plus https://faucet.solana.com, then funds updater and trader from the admin. Keys in `~/.config/solana/propamm-devnet/`. `scripts/devnet-deploy.sh` deploys and then runs it; config `data/devnet.json`.
- Devnet resume: `setup --cluster devnet --base-mint M --quote-mint Q` skips existing mints, market and deposits, mints and deposits only the missing amount, and forces a price only when the mid is 0. `chain.rs` retries 429/5xx/timeouts (`backoff_delay`, `parse_retry_after`; never `requestAirdrop`); `run` takes `--status-poll-ms` and `--refresh-ms` (defaults chosen by the parsed RPC host via `is_local_rpc`: 200 and 2000 ms local, 1000 and 3000 ms remote). Stop `run`/`record` with `kill -TERM <pid>` (or Ctrl-C): `shutdown_signal` listens for both, and a nohup job started from a non-interactive shell has SIGINT ignored, so SIGTERM is the reliable one.
- Instruction encoding lives in `crates/client`, not here.
- Local E2E: `scripts/localnet.sh`, then `propamm-bot run --config data/localnet.json` (`--rpc`/`--ws` default to the config). The policy holds when market state is older than 6 s. Keypairs live in `~/.config/solana/propamm-local/`, outside the repo. Needs `target/deploy/propamm.so`.
- TLS: reqwest uses `rustls-no-provider`; `main` installs the ring provider once.
- `solana-hash` needs the `copy` feature (otherwise `Hash` is not `Copy` unless another crate in the build turns it on).
